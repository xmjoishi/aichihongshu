## 图形主标

主图形是一个简洁、饱满的红色红薯形体：

- 主体使用明亮品牌红，形状圆润并向右上收尖。
- 右上方保留一个金色月牙形咬口，咬口表达“吃红薯”，也是图形记忆点。
- 咬口上方或相邻位置配一枚金色四角星光，表达 AI 灵感、记录和生活的闪光点。
- 不使用旧版的绿叶、深酒红阴影、复杂纹理、拟人五官或紫红薯配色。
- 图形应在小尺寸下保持“红薯 + 金色咬口 + 星光”三项识别关系，不增加细碎装饰。

## 字标和版式

- 中文字标为粗黑、圆润、易读的无衬线风格，主显示为“爱吃红薯”。
- slogan 使用灰蓝色、较轻字重，置于中文主字标下方。
- 横版组合优先采用“左侧图形 + 右侧中文主字标和 slogan”的关系。
- 英文 `AI CHIHONG SHU` 使用全大写、宽字距的小字标；不替代中文主字标。
- “V2.8 BRAND IDENTITY”设计板中的说明文字属于规范展示内容，不属于产品运行时必须展示的 UI 文案。

## 图标版本和尺寸

设计板定义三种图标方向：

1. 标准版：米白底 + 品牌红主体 + 灵感黄细节。
2. 反白版：品牌红底 + 白色主体 + 白色星光，适合品牌色背景。
3. 单色版：深色背景 + 白色主体，适合深色模式或单色印刷。

需要导出 128 px、64 px、32 px、16 px，并在每个尺寸检查咬口和星光是否仍清晰。App icon、Dock icon、favicon、侧栏 Logo 可以使用同一主图形的不同安全留白版本。
