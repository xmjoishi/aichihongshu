# 接口去留清单（执行版）

> 适用范围：`app/routers/*.py` 当前全部 REST 接口
>
> 目标：把接口按「前端替代 / 迁 Tauri command / 保留后端」分组，直接用于排期。

---

## 1. 分组原则

- `前端替代`：纯派生计算、无 IO、无密钥、无系统能力。
- `迁 Tauri command`：本地文件/配置/SQLite 基础能力，桌面端自调用更合理。
- `保留后端`：AI、爬虫、自动发布、SSE、风险保护、复杂异步任务。

---

## 2. 结论总览

### 2.1 前端替代（优先级最高）

- `GET /api/analytics/summary`
- `GET /api/analytics/insights`
- `GET /api/analytics/notes-trend`
- `GET /api/analytics/topics`

说明：以上 4 个接口都属于聚合统计，数据源来自 `notes/items/my_profile/reference_accounts`，前端 selector 可直接计算。

### 2.2 迁 Tauri command（中期）

- `GET /api/settings/env`
- `PATCH /api/settings/env`
- `GET /api/settings/prompts`
- `PUT /api/settings/prompts/{key}`
- `POST /api/settings/prompts`
- `DELETE /api/settings/prompts/{key}`
- `POST /api/content/{note_id}/open-stage-dir`
- `GET /api/library/{item_id}/image`（或替换为本地文件读取命令）
- `GET /api/library/trash/list`
- `POST /api/library/trash/{item_id}/restore`
- `DELETE /api/library/trash/{item_id}/purge`
- `DELETE /api/library/trash/purge-all`
- `POST /api/crawler/browser`
- `DELETE /api/crawler/browser`
- `GET /api/crawler/browser`
- `POST /api/crawler/open-url`

说明：这些接口本质是“桌面系统能力 + 本地数据操作”，长期走 localhost HTTP 成本偏高。

### 2.3 保留后端（长期）

- 全部 `ai/*`
- 全部 `crawler/*` 中真正触发爬虫子进程的接口（如 `/creator`）
- `POST /api/content/{note_id}/publish-auto`
- `GET /api/content/{note_id}/publish-status/{job_id}`
- `GET /api/content/xhs-login-status`
- `POST /api/library/{item_id}/analyze`
- `POST /api/accounts/{account_id}/analyze`
- `GET /api/accounts/{account_id}/insights`
- `POST /api/accounts/{account_id}/imitate`

说明：涉及 API Key、SSE、Playwright、MediaCrawler、风险保护、长任务轮询，不建议下沉到前端。

## 4. 迁移顺序建议

1. 先做 `analytics` 前端替代（风险最低、收益最高）。
2. 再做 `settings + trash + open-dir` 的 Tauri command 化。
3. 最后评估 `content/library/profile/accounts` 基础 CRUD 是否继续走 HTTP。

---

## 5. 验收口径

- 页面功能不回退（以现有 UI 行为为准）。
- 聚合结果与旧接口误差在可接受范围（0 或规则内差异）。
- 自动发布、爬虫、AI、风险保护能力不受影响。
