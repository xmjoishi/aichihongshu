# CHG-20260925-005 编辑页图片条体验

## 目标

编辑笔记页图片条改为小红书式干净交互：图面只留照片，排序长按拖动，封面=第一张，点图全屏预览。

## 现状

每张缩略图（108px）上叠 5 个控件（封面角标、设封面、‹、›、×），首图「封面」与「设封面」语义重复，控件压图显乱。

## 范围

- 缩略图放大到 120px、圆角加大，只保留右上角圆 × 删除。
- 首图仅显示「封面」小角标；去掉「设封面」按钮。
- 排序：长按拖动（`activateAfterLongPress` + Pan），拖到首位即封面；去掉 ‹ › 箭头。
- 点图全屏预览，点空白/× 关闭。
- 根布局补 `GestureHandlerRootView`。
- 二轮扩展：图条「加图」入口（相册多选入库）；点首图进小红书式笔记预览页（图+标题+正文+发笔记）；预览页内 3:4 封面预览；话题输入关键字联想历史话题。
- 七轮扩展（用户 2026-09-27 明确执行）：照片来源以系统相册为准，应用只保存照片引用与自己的标签、分析和使用元数据，不复制图片文件；只有发生实际使用时才创建应用素材记录/ID。
- 已确认使用触发点：AI 创作消息实际发送图片、明确开始 AI 图片分析、笔记保存时保留图片关联，以及其他实际提交图片的使用入口。仅打开页面、浏览、临时选择或取消不入库。
- 编辑页和对话页选图先以临时 URI 即时预览；保存/发送/分析时再创建或复用素材 ID。删除尚未提交的临时照片不产生素材记录。
- `items` 记录系统资产引用（优先保存系统 assetId，兼容 URI 回退）、标签/分析/使用来源；系统相册负责原图与权限。`已入库` 是记录存在状态，`已分析/未分析` 是分析状态，`已使用` 是独立使用状态，不做互斥枚举。
- 相册主页面改称「相册」，继续按 iOS 有限照片权限展示用户授权可见的系统照片；不把整本相册批量建成应用记录。

## 非目标

- 不做替换单张图片、裁剪、滤镜等图片编辑。

## 已确认决定（用户 2026-09-25）

| 决定 | 选择 |
| --- | --- |
| 排序 | 长按拖动（小红书同款） |
| 封面 | 第一张即封面 |
| 预览 | 点图全屏预览 |
| 相册状态角标（2026-09-27） | 照片格左下固定一枚 18px 深色圆底状态标记：灰色书签表示已入库未分析，黄色星芒表示已分析（已分析必然已入库）；多选时继续显示。右上角红勾只表示选中，红色蒙层减淡、边框 2px；已使用由筛选/详情呈现 |
| 相册权限入口（2026-09-27） | 网格首格保留「＋ 添加」入口，打开 iOS 有限照片权限选择器并在返回后刷新照片；不因此创建应用素材记录。limited 提示条入口也保留 |

| AC-01 | 进编辑页看图条 | 大图干净，仅右上角 ×、首图「封面」角标 |
| AC-02 | 长按缩略图拖到别的位置 | 顺序更新；拖到第一位后该图显示「封面」 |
| AC-03 | 点缩略图 | 全屏预览；点空白或 × 关闭 |

| AC-05 | 点图条末尾「加图」并选择照片 | 选择结果立即追加到图条；不复制图片、不立即创建素材 ID；保存笔记关联或实际用于 AI 时才创建/复用照片记录 |
| AC-06 | 点首图 | 打开笔记预览页：大图横滑、标题正文话题、底部「预览封面/发笔记」 |
| AC-07 | 预览页点「预览封面」 | 弹出 3:4 封面框；「发笔记」进发布准备页 |
| AC-08 | 话题输入框输入关键字 | 出现匹配历史话题；点选后成为标签 chip |
| AC-09 | 打开底部「相册」 | 显示系统相册中当前授权可访问的照片；浏览或滚动不创建素材记录 |
| AC-10 | 多选照片后取消，或在笔记页移除未保存照片 | 不创建素材记录/ID；系统照片不被改动 |
| AC-11 | 从照片触发 AI 创作并实际发送、触发 AI 分析、或将照片关联到笔记并保存 | 为实际使用的系统照片创建或复用一个应用素材 ID；未使用照片没有应用 ID |
| AC-12 | 在相册查看状态筛选 | 区分「已入库」「已分析」「未分析」「已使用」；分析与使用可同时成立 |
| AC-13 | 收回照片权限或从系统相册删除照片后查看已标注记录 | 应用保留标签/分析/使用元数据并显示原图不可访问提示；不删除或改写系统照片 |
| AC-14 | 在任意相册状态筛选下查看网格并点首格「＋ 添加」 | 「＋」入口始终可见；打开系统照片访问权限选择器，返回后照片列表刷新；不创建素材记录。用户于 2026-09-27 20:56 确认验收通过 |
