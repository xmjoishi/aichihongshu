## 实施记录

### 2026-09-26 多 Model API 配置与真实调用链

1. **Rust `model_api.rs`**
   - 配置结构：`ModelApiSettings { providers[], defaultProviderId, defaultModel }`，存 `app_settings` key `model_api_settings_v1`。
   - Provider：`kind: openai-compatible | anthropic-compatible`、endpoint、api_key、model、visionModel、enabledModels、builtin、preset。
   - 预置目录：DeepSeek / MiniMax / OpenAI / Anthropic（builtin）+ OpenRouter / SiliconFlow / 智谱 / 火山方舟 / Ollama（可连接模板）。
   - 读取视图脱敏（`apiKeyMasked` + `configured`）；API Key 不回传前端、不写日志。
   - 流式：`ureq` POST + SSE 逐行解析（OpenAI `choices[0].delta.content` / Anthropic `content_block_delta.text`），事件复用 `local-ai://chunk|done|error`。
   - 初版取消：`ModelApiRuntime` 按 runId 存 `AtomicBool`；因同步 SSE 行读取会阻塞，停止标志只能在下一行到达时检查。
   - 2026-09-28 审查修复：交互式 SSE 改为 Reqwest 异步分块读取；`ModelApiRuntime` 按 runId 保存 Tauri 任务句柄，取消会 abort 任务并丢弃响应连接。同步 `ureq` 仅保留给短时测试连接。

2. **命令**
   - `read_model_api_settings` / `upsert_model_api_provider` / `delete_model_api_provider`
   - `set_model_api_default_target` / `test_model_api_provider`
   - `start_model_api_run` / `cancel_model_api_run`

3. **前端**
   - `ModelApiProvidersSection`：已连接 / 未添加分组、自定义 Provider 表单、测试连接、设为默认、删除。
   - AIPanel 选择器 Model API 段列出已连接 Provider（`model-api:<id>`），无配置时提示先连接。
   - `useAIStream` 新增 `connection: "model-api"` 分支，走 `streamModelApi`。

### 边界

- 不宣称图片/工具能力；visionModel 仅配置位。
