# PC 性能修复技术设计（2026-09-27）

归属 CHG-20260921-002；最新授权：用户要求全部修复本轮排查的问题。

## 页面生命周期

`WorkspaceActivity` 由外壳设置，不能依赖保留页内部冻结的路由判断可见性。`useWorkspaceQuery` 隐藏时禁用查询、轮询和结果更新通知；重新显示由 React Query 的过期/失效机制补读。`useWorkspaceEffect` 只用于页面事件、轮询、上下文发布和可推迟的探测。AI 流订阅、自动保存和初始化草稿不整体套此机制，避免丢失运行/编辑。账号隔离遵循同期 AC-21 的账号快照边界。

App 按账号 scopeKey + 首级菜单保留最近访问的路由实例和 location，并对全部账号合计设置 18 页上限。新增访问会刷新 LRU 顺序并淘汰最久未访问页；淘汰页再次进入时正常重新挂载，避免用户反复切号/菜单造成隐藏页面无限累积。

## 查询和失效

本地查询统一为 `[local-workspace, scopeKey, section]`。section 分为 library、notes、profile、references、summary 和 workspace，分别读取所需集合；同资源跨页面共享缓存。筛选、搜索与排序只在派生列表处理，不进入本地快照键。所有原有写操作失效入口改用账号前缀，避免只更新旧别名缓存。

Rust `read_status` 接受可选 section。旧调用不传时保持 all 完整快照；原有数据库函数保留兼容。library 仍检查原图存在并包含素材回收站，notes 保留笔记回收站及编辑所需素材，summary 只需计数（保留兼容字段结构），其他资源不扫描全量素材文件。不改变数据库结构和原有 5000 条读取上限。

## 图片与大列表

`LocalImage` 通过共享 IntersectionObserver，在视口附近 240px 才进入最多四并发的读图队列。隐藏、离屏或卸载后不启动排队读取，已发出的结果不能回写旧组件；按数据库、账号、素材版本、变体隔离缓存。缓存上限 128 项及估算 32MiB 字符串空间，离屏释放组件持有的图片数据。原生图片读取在 blocking task 执行，避免文件读取/Base64 转换阻塞桌面命令线程。

素材网格以固定图片比例和有界标题区计算完整滚动高度，只挂载可见行及上下两行；窗口/侧栏变化通过 ResizeObserver 重算。保留选择全体结果、滚动位置和详情操作。笔记列表卡片使用 content-visibility 跳过离屏绘制；瀑布流卡片不使用尺寸包含与离屏占位，以真实高度参与多列平衡，并用完整宽度的 inline-block 保持整卡不可拆分（2026-09-28 修复，原生待复验）；封面统一缩略图；素材与笔记映射/筛选/排序使用 useMemo，笔记编辑按 ID 定位后转换，避免每次输入转换全部笔记和素材。

## 桌面阻塞命令

模型连接测试、模型列表、CLI 模型扫描和本地图片读取统一进入 blocking task。模型列表总超时 30 秒；流式请求连接超时 10 秒、空闲读取超时 60 秒（不限制持续输出的总时长）；OpenCode 扫描超时 30 秒后终止子进程，并在等待期间排空 stdout/stderr，避免管道塞满。
