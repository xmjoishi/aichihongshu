## 用户授权

用户确认并授权完整范围：

1. 网页收藏使用参考现有笔记瀑布流和小红书 Web 的卡片体验：首张已本地化的收藏图做封面、图片保留比例、标题最多两行、作者/来源/收藏时间、多图数与本地化失败小标记；移除重复类型和“已收藏”大栏。没有图片时显示简洁文字卡，不造图。
2. 卡片打开详情弹层：左侧本地图片轮播，右侧标题、作者、已采集正文、标签、已选评论；支持键盘切图、图片放大、Escape 关闭、焦点管理与窄窗口适配。
3. 支持标题/正文/作者搜索，来源、收藏时间和标签筛选；支持备注、标签编辑、取消收藏；转草稿与加入创作素材放在详情中。
4. 用户在插件明确勾选的图片按原顺序本地化；未勾选图片不下载。保留原图和独立缩略图，列表与详情都从本地读图；离线可读，远程 URL 仅作来源证据。
5. 图片逐项保存进度与失败原因。正文成功但图片不全时明确显示“文字已保存，图片 2/4”；重试只处理失败项且不重复收藏/导入，不把部分结果说成全部成功。
6. 老收藏提供补全本地图片入口；旧 URL 失效时解释需要回原页重新采集。
7. 图片附件属于收藏，不自动写进创作素材库；用户明确“加入创作素材”后才关联或复用其本地文件。

### 下载约束

- 只处理扩展已选、协议已筛选的公开 HTTPS 图片；每个重定向目标重新校验，拒绝私网、回环、本机、链路本地及非标准端口。下载使用无 Cookie 客户端，不复用/复制浏览器登录会话。
- 单收藏最多 12 张，每张最多 25 MiB，合计最多 32 MiB；网络超时、内容长度上限、实际 MIME 与图片魔数均需校验。
- 远程下载遇到 XHS/CDN 登录、签名、热链或跨域限制时如实失败，保留正文与来源 URL，提示回原页重新采集。不得宣称 Rust 裸请求一定能取回所有图片。
- 图片文件使用与本账号创作素材相同的摘要路径约定，但由独立收藏附件记录持有；转成创作素材需用户主动执行。删除收藏时先删除附件引用；只有确认不存在任何收藏/创作素材引用后才可清理文件。
