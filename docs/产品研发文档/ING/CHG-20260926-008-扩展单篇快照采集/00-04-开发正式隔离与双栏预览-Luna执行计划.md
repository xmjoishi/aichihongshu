## 已核实的问题与证据边界

1. `browser_capture.rs` 安装清单将完整应用设为 path，并写入 `args: ["--native-messaging-host"]`；`main.rs` 依赖该参数才进入无界面宿主。Chrome 官方宿主清单不提供 args 字段，真实启动会传调用扩展 origin。此契约错误与截图多开应用/无回执高度吻合，尚需安装清单与实际进程参数复现确认，不能把截图推断当作现场日志。
2. `check-native-host.mjs` 手工追加该参数，绕过真实启动契约，产生测试覆盖缺口。
3. popup 的 Native 请求与持续 Port 请求缺少前端 deadline；解析预览又等待账号/归属查询，因此可能评论已出现而顶栏仍显示解析中。
4. socket 启动直接删除固定路径，多实例可能抢占；当前路径与宿主名称缺少开发/正式隔离。
5. 图片查询复用优先命中 `#detail-desc` 的正文容器，轮播区在其外时会漏图；真实站点 DOM 仍需样本确认。
6. 评论默认展开占用空间，主操作在页面底部；配置与预览混排，连接、解析、保存状态未分开。

参考：[Chrome Native Messaging 官方契约](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging)。执行时核对最新契约。

## 已对齐的产品方案

- 正式与 dev 为两个独立扩展构建，可同时安装；正式保持既有扩展 ID，dev 使用独立且稳定的 ID、名称和 DEV 标识。不要每次构建随机生成 ID。
- 两通道使用不同宿主名称、安装目录、socket、锁和连接状态；dev 不覆盖正式安装清单或扩展资源。连接失败不自动跨通道回退。
- UI 展示通道、应用版本和工作区友好标识；详细路径仅在调试详情按需展示。连接验证应核对通道/工作区身份，目标账号列表来自已确认的连接。开发 QA 使用隔离资料；不要隐式迁移、复制或清空现有数据库。
- 宿主启动只运行无界面转发器。目标应用不在线时明确提示启动对应版本，不自动拉起完整 GUI。
- 同通道仅一个监听服务；正式与 dev 可共存。不同 dev 工作区不能自动互抢：当前 dev 安装绑定一个明确工作区，需要切换时显式重新注册并显示目标。
- 宽版工具栏弹窗采用左右栏：左侧约 220–240px，放账号、页面类型、收藏/更新模式和模块开关；右侧占其余空间，显示实际待保存内容。建议以约 760×560 CSS px 起步，按 Chrome/Edge 实际 popup 限制与缩放验证调整。
- 顶部状态区和底部操作栏固定，左右内容独立滚动；正文/评论尽量避免多层嵌套滚动。小尺寸可降级上下布局，主按钮始终可达。
- 收藏预览：标题、正文、作者/来源、图片网格、评论摘录；图片/评论在右侧勾选，左侧显示模块开关与已选数量。关闭模块时预览明确不保存；折叠列表不清除选择。
- 更新预览：本次值、上次同账号同对象快照及变化；没有可比样本或指标未识别时显示未知，不填 0，不称为精确日增量。
- 提供“展开预览”独立扩展页面，复用同一预览组件/数据模型；绑定原始来源 tabId/URL/解析批次，打开新页后不得把新活动标签当采集源。不新增宽泛站点权限；原标签关闭、导航或授权失效时明确要求重新解析。页面关闭后清理临时会话，不长期保存正文/评论/令牌。
- 展开预览增加 `storage` 权限，但只使用一次性的 `chrome.storage.session`，不写 local/sync storage；扩展页 URL 不带正文、评论、来源 URL、会话 key 或令牌。

## 必须补齐的自动验证

- 从生成的 Native Host manifest 读取 path，按浏览器形式只传允许的扩展 origin（不要测试程序偷偷补宿主模式参数），发送长度帧，验证有效 ACK、错误帧、断连及持续 Port 多帧。无 UI 可用可观测的启动分支验证；真实浏览器是否弹窗仍由产品验收确认。
- 双通道安装、升级、卸载各自作用域；错误 origin/通道/工作区身份明确拒绝，不返回另一个环境的账号数据。
- 多进程争用、陈旧 socket、旧进程退出时新 owner 已接管；使用隔离临时路径，不能碰用户正在使用的 socket。
- 宿主不响应、崩溃、延迟回包、重试、账号切换/页面导航中的竞态；写入超时后的状态核实与幂等性。
- 图片 fixture 包含正文与轮播为兄弟节点、懒加载未就绪、重复图、头像、推荐区、未知尺寸与不合格 URL；普通网页/主页解析不回归。
- UI 测试覆盖窄高度、缩放、长正文、0/1/多图片、长评论、未知指标、账号切换、右侧选择与 payload 一致性、展开预览绑定来源标签、来源导航与关闭。不得只靠字符串门禁声称交互已验证。
- 回归现有快照持久化 ACK、账号隔离、同请求幂等、Creator 图片填充和 AI 复盘。命令入口先以当前 package/Cargo 定义核实，沿用 check:browser-capture、check:native-host、check:browser-extension-package、前端 build 与相关 Rust suites。
