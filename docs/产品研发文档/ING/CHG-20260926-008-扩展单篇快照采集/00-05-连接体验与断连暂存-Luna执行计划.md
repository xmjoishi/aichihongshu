# 浏览器连接体验与断连暂存：执行计划

- 日期：2026-10-01
- 所属：CHG-20260926-008，沿用现有任务。

状态：代码与自动验证完成；真实浏览器/桌面产品验收待办。

## 用户已确认范围

1. 日常默认使用正式插件。高级开发模式允许选择并记住开发实例。只有一个匹配实例时自动连接，多个实例时由用户选择；显式绑定的实例离线时不自动转到其他数据库。打开扩展只检测连接；只有用户点击对应操作后才启动桌面 APP。
2. 连接分层诊断顺序为插件 → 浏览器 Native Messaging 宿主 → 桌面实例 → 版本/协议握手 → 账号读取。准确区分宿主缺失、旧注册、宿主启动失败、目标实例离线、协议不兼容、账号读取失败和未知超时；每类给出针对性操作。
3. 桌面端检查注册清单/可执行路径并验证插件实际通信；提供一键修复入口和复制脱敏诊断。诊断只包含组件版本、通道、失败步骤、错误码、耗时，不包含账号内容、网页正文、账号凭据或敏感路径。
4. 断连保留用户选择。仅在用户主动点击后才把采集请求暂存到浏览器，并明确标注“尚未保存到桌面”。恢复后复核原目标账号，再由用户主动保存。写入超时或回执不明时按原 requestId 查询，避免重复入库。

## 安全与文档边界

- 浏览器注册 `allowed_origins` 保持精确扩展 ID，不使用通配符。DEV host 若允许正式固定 ID 调用，必须同时保留原 DEV ID，并通过正式/DEV、工作区和协议检查。
- 实例清单仅供本机同用户读取，owner-only 权限；Native Messaging 回给扩展的实例元数据不含可执行文件或项目绝对路径。脱敏诊断不复制任何路径。
- 页面正文、评论、图片 URL 只在用户点击“暂存到浏览器”或已开始发送且结果不确定时写入 `chrome.storage.session`；不使用 local/sync 存储网页内容。明确暂存在浏览器会话内保留，不自动提交。
- 不提交或推送，不操作正式账号发布，不改 `tools/MediaCrawler`。真实 Chrome/Edge 与 Tauri 桌面验收由用户执行。
