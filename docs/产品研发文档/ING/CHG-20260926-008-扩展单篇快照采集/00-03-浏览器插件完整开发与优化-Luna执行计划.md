## 技术约束与关键实现决定

### 协议、持久化和账号

- 新协议版本由实际契约变更统一递增，manifest 是扩展版本唯一来源。握手包含协议范围、能力、扩展版本；不只发送版本而不校验。兼容至少现有 v3 剪藏入口，未知操作拒绝且不写库。
- 收藏与快照作为独立模块报告结果：允许一项成功一项失败，但必须明确展示，重试只补失败项。同账号、requestId、操作模块建立幂等约束；复用请求却更换有效载荷须拒绝。超时显示“结果待核实”，通过只读状态查询核实，不能盲目重复提交。
- 插件传入账号只能作为选择请求；Rust 校验账号存在、可用、属于当前本地工作区，返回绑定数据库身份/账号/有效期的上下文标识。提交重新校验标识与目标。不得退回静默使用另一个账号；旧 v3 保持当前激活账号语义。
- 账号选择只列必要的名称/标识，不暴露凭据；切换目标后重新查询 URL 归属、预览与历史状态。桌面全局账号切换不得改变已经确认的目标；失效时明确要求重新选择。
- 快照全保留、按采集时间排序；同 requestId 幂等，新的一次手动采集产生历史。新增存储使用版本化迁移；迁移失败保留原数据与可诊断状态。收藏旧队列迁移继续保留账号隔离与失败重试。

### 图片、评论与解析

- “图片清单”包含 URL、可获取的尺寸、顺序与来源，排除头像/图标；不自动翻页、滚动抓取或加载更多。用户选择后才导入本地素材，复用现有摘要去重、文件类型/大小校验与素材关联。
- **历史实现调整（P3，2026-10-02 被最新授权覆盖）**：当时插件只保存公开 URL 引用，由用户下载后手工导入；自动远程导入及失败路径未实现。当前应按 00-06 计划实现受限公开 HTTPS 下载、本地收藏附件与逐项失败恢复，不复用浏览器 Cookie。
- 评论仅收录已加载且用户选择的片段，保留截断标识和来源。它不是完整评论统计，也不参与编造总体结论。图片/评论设置条数、长度与总大小上限，超出时可见截断。
- 富文本和页面数据一律作为不可信内容处理；展示不得执行 HTML/脚本。解析器输出字段来源与缺失原因；选择器失效时降级并提示，而非显示虚假的成功完整度。

### 发布填充

- 复用本地发布准备和图片暂存，不创建另一套发布状态。明确区分待填充、填充中、部分失败、已填充待人工提交、结果待核实、用户确认已发布。
- 最小权限仍优先 nativeMessaging/scripting/activeTab；采用用户在目标页点击插件领取单条任务。任务绑定本地账号、笔记、版本、一次性授权和期限；不让任意网页索取本地任意文件。
- 图片通过受限文件标识和有界分片传输，禁止任意绝对路径；校验 MIME/魔数/总大小/顺序。真实页面不支持可靠上传时，不得仅用“打开文件夹”冒充自动填充完成；记录具体阻塞，继续其他阶段。
- 页面已有内容时先展示差异并由用户选择替换/取消；取消后不再注入。重复点击不重复追加正文/图片。所有填充操作止于发布按钮之前。
- 不额外要求平台账号与本地运营账号凭证绑定，但填充前展示目标网页账号（能识别时）和本地账号，无法识别明确提示，由用户核对。

### 趋势与 AI

- 只比较同账号、同对象、同指标的可比快照；缺值留空、计数下降如实显示。累计值之差命名为“快照间变化”，不能称为精确日增量；不补造没有采样的日期。
- AI 只在用户点击时运行，复用现有 Provider 配置，不另建 Key 系统。发送前显示数据范围，默认不发送评论作者或图片原件；网页/评论文本作为证据数据，不能当作模型指令。
- 洞察包含样本数、时间范围、引用快照和证据不足说明；区分观察、推测和建议，不声称因果。保存复盘时记录所用快照 ID、模型与生成时间，用户可编辑，不自动改稿或发布。

### 分发

- 当前复制目录功能继续复用；补完整资源清单与完整性校验，防止漏文件。更新使用稳定加载目录和可恢复替换，保留固定扩展 ID；提醒浏览器重载，不能声称程序已替浏览器重载。
- 安装器明确区分宿主已安装、应用在线、浏览器扩展已连通、协议兼容。升级失败可恢复上版；卸载只处理自身扩展/宿主资源，不删除业务库。
- 首轮正式交付矩阵为 macOS Chrome/Edge，记录实际系统、浏览器、应用/扩展版本。商店上架材料包含权限说明与隐私说明，但不得无授权对外提交；其他系统作为明确未支持项，不伪装跨平台可用。
- **P7 实施决定**：在桌面 Rust 可执行文件加入 `--native-messaging-host` 入口，以有界长度帧直连 owner-only Unix socket；不再依赖系统 Node 或仓库中的 host.cjs。7 个运行资源用 `include_bytes!` 编进 app executable；安装时先在同目录暂存、核验 SHA-256/manifest ID，再原子替换稳定用户目录，失败保留原目录，成功留存 previous 副本。旧 `host.cjs` 仅保留作兼容 harness。根脚本 `check:native-host` 会编译 app binary 并实测四种 IPC 场景。当前 `npm run tauri:build` 在 Cargo `[[bin]] rn` 因工作树缺少 `src/bin/rn.rs` 处失败，因此真实 Tauri `.app` 包与干净机安装尚未完成验证；不在本 CHG 擅自删除/伪造该并行 target。
