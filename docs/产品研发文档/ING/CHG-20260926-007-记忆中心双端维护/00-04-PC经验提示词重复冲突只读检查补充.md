# CHG-20260926-007 补充：PC 经验提示词重复与明确冲突只读检查

更新时间：2026-10-05

## 范围与行为

- PC「记忆 → 经验提示词」新增本地只读检查；手机页不展示此检查。
- 重复检查比较正文。统一全半角、大小写、首尾空白及连续空白后正文相同，即展示成对建议。
- 冲突检查只比较同时启用、账号范围有重叠、且出稿/对话适用场景有重叠的提示词。
- 当前只识别可引用原文证据的明确偏好对立：Emoji 使用与禁用、小标题使用与禁用、分段与整段、列表/分点与禁用列表。不会把“自然/正式”等一般自然语言风格差异判成冲突。
- 每条建议展示命中的提示词标题和规则片段，并提示人工复核。检查在本地运行，不调用外部 AI；没有修改、删除或停用任何提示词。

## 实施文件

- `client/src/pages/memory/MemorySections.tsx`：PC 经验提示词只读建议区。
- `client/src/pages/memory/experiencePromptReview.ts`：纯逻辑比较与证据生成。
- `client/scripts/test-experience-prompt-review.cjs`：重复/冲突规则、适用范围过滤与 PC-only 展示回归。
