# 手机 Companion 真实链路：变更确认卡

任务：CHG-20260922-003
状态：实施中
日期：2026-09-22
基线：`1f4865a` + CHG-20260921-002 执行中修改
上游：CHG-20260921-002 C 线；Roadmap 阶段 C

## 目标

打通「手机拍照/主题 → PC Harness 任务 → 稿件拉取 → 人工发布回填」最小真实闭环：PC 端提供用户显式开启的局域网 Harness 服务（配对令牌鉴权），手机端任务 UI 调用同一客户端契约完成上传、查询、取稿与回填。

## 现状

- 手机侧已有 PC Harness 配置（地址/令牌安全存储、健康检查）与 `create/harness.tsx` 最小任务入口、`pcHarness.ts` 客户端契约。
- PC 侧尚无监听服务；CHG-20260921-002 明确将 PC 服务端排除在该批之外。
- 本地草稿、素材导入、发布 outbox 已具备，可复用为任务落库能力。

## 范围

- PC Harness 局域网服务：仅在用户显式开启后监听；Bearer 配对令牌鉴权；绑定本机局域网地址。
- API（`/api/mobile/v1`）：`GET /health`、`POST /companion/tasks`、`GET /companion/tasks/:id`、`GET /companion/tasks/:id/draft`、`POST /companion/tasks/:id/publish-receipt`。
- 任务生命周期：`clientTaskId` 幂等；照片导入素材并建关联草稿；主题写入草稿正文种子；账号在创建时冻结。
- 桌面设置入口：开启/停止 Harness、展示配对地址与令牌、显示服务状态。
- 配对：PC 在 Harness 运行且检测到局域网地址时本地生成二维码；手机扫描后校验配对协议与 LAN 地址，先通过健康检查再安全保存配置。二维码不发送到第三方服务；轮换令牌使旧码失效。
- 手机任务 UI：真实上传、状态查询/轮询、取稿、发布回填，错误可操作；手机配置页支持手动录入与相机扫码。
- 隔离 QA 数据验证；不自动提交、不推送、不动正式账号数据。

## 非目标

- 不做小红书自动发布、无人值守、防封或批量采集。
- 不做真实多模态图片理解与 AI 自动成稿（本批草稿为主题种子 + 素材关联；AI 生成仍走既有桌面/手机 AI 路径）。
- 不做手机与桌面 SQLite 合并、不做旧手机数据自动迁移。
- 不做跨页自主 Agent、虚拟账号/共享资产。
- 不修改 `tools/MediaCrawler`、NOOMD、官网、正式 `data/` 与凭据。

## 已确认决定（用户授权「执行」）

- 优先交付「PC Harness 服务端 + 手机任务 UI 真实链路」。
- 首期同 Wi-Fi、用户在小红书 App 最终发布并回填；以租房家居账号为首个验收样板。
- 账号作用域在任务创建时冻结；切换桌面账号不改写已有手机任务归属。
- 导出/跳转/回执不等于平台发布成功；`confirmation` 需用户回填。

## 待决事项

- 真实图片理解接入与模型能力矩阵（后续切片）。
- 断网离线缓冲与断线恢复的完整体验（本批仅保证不重复建任务、可查已有任务）。
- 小红书分享 SDK 是否接入（保持人工交接）。

## 验收条件

| AC | 步骤 | 可观察预期 |
| --- | --- | --- |
| AC-01 | 未开启/未配对访问 Harness | 无监听或 401，手机无法建任务 |
| AC-02 | PC 开启 Harness，手机录入地址与令牌并健康检查 | `ok=true`，协议版本一致 |
| AC-03 | 同 Wi-Fi 上传多图 + 主题（或仅主题） | PC 素材库出现图片；生成关联草稿；任务 `ready` |
| AC-04 | 重复同一 `clientTaskId` 提交 | 幂等，不重复建稿/不重复导入 |
| AC-05 | 手机拉取稿件 | 标题/正文/标签/素材关联与 PC 笔记一致 |
| AC-06 | 人工发布后回填 URL/状态 | PC 端任务与笔记可见回填结果；未确认不标平台成功 |
| AC-07 | 创建后切换桌面账号再查询任务 | 任务仍归属创建时账号，不串写 |
| AC-08 | 停止 Harness 后手机请求 | 连接失败且错误可读；PC 无残留监听 |
| AC-09 | PC 开启 Harness 后在手机扫描配对二维码 | 手机校验本地目标和协议、健康检查成功后安全保存地址与令牌；无效/公网目标不保存，轮换令牌后旧码不可连接 |
