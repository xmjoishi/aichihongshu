# CHG-20260926-008 AI 设置页重构：变更确认卡

## 目标

1. 修复设置页内容未居中。
2. AI 设置页参考 Noomd 重排：置顶「新会话默认使用」、CLI/API 分层、Provider/CLI 管理弹窗、即时保存。

## 现状

- `Settings.tsx:109` 内容容器 `max-w-2xl space-y-6` 缺 `mx-auto`，整体贴左。
- AI 页为四块上下堆（默认接入 radio、Model API 列表、Agent CLI 简表单、保存按钮）；无默认模型置顶选择器、无 CLI/API 子 tab、enabledModels 为逗号文本框、显示方式混在接入配置、保存语义不统一。

## 范围

1. 设置页内容居中（宽度对齐 Noomd 760px 量级）。
2. AI 页内部重排（不动设置顶栏 Tab）：
   - 置顶「新会话默认使用」卡片 + 弹出选择器（API/CLI 双 tab、搜索、按 Provider 分组）。
   - 「本地 CLI」|「API Provider」子 tab。
   - 「显示方式」移出接入配置。
3. 管理弹窗：
   - Provider：endpoint/key/label + 启用模型清单（勾选、全选、刷新模型、手动添加）。
   - 本地 CLI：卡片三态 + 管理弹窗（启用模型清单、刷新、移除/重连）。
4. 即时保存：去掉底部大保存按钮，改动即落盘；危险操作单独确认。

## 非目标

- 不改设置页整体导航形态（不引入左侧设置导航）。
- 不做模型元信息目录（上下文/价格）、费用统计、Keychain、Provider fallback。
- 不改 Agent CLI 运行链路与 Model API 调用协议。

## 已确认决定（2026-09-26）

1. 只改 AI 页内部。
2. 架构 + 管理弹窗全套。
3. 即时保存。

## 验收条件

- AC-01：设置页各 Tab 内容水平居中。
- AC-02：AI 页含「新会话默认使用」置顶卡，可选 API Provider 或 CLI 的具体模型并即时生效。
- AC-03：AI 页含 CLI / API Provider 子 tab；显示方式不在接入配置内。
- AC-04：Provider 管理弹窗可勾选启用模型、全选、刷新模型、手动添加并即时保存。
- AC-05：本地 CLI 卡片显示三态，管理弹窗可维护启用模型清单。
- AC-06：改动即时保存，重启后保持；无底部大保存按钮。
- AC-07：`cargo test --lib`、`npm run build` 通过；原生验收 AC-01–AC-06。
