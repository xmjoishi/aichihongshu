### 2026-09-26 补充：启用清单按 CLI 隔离（修模型串）

用户反馈「模型扫错了」：OpenCode 的 `opencode/nemotron-…` 出现在 Claude 管理弹窗。

- 根因：`AiAgentCliSettings.enabledModels` 是全局一份 `Vec<String>`，三个 CLI 共用；扫描任一 CLI 的结果会串到其他 CLI 的勾选池。
- 修复：改为 `HashMap<String, Vec<String>>`（key=claude/codex/opencode），管理弹窗与默认选择器按 CLI 读写；旧数组数据读取时自动迁移到当前 provider（默认 claude）。
- 「选不到了」：截图下拉仍为旧样式（全宽、`Claude CLI ·` 前缀、扁平分组），判断为旧构建；同时已把 `applyDefault` 的静默失败改为明确报错，避免点了无反馈。

`cargo test --lib` 36 passed。需 `npm run tauri` 重新构建后验收。

### 2026-09-26 补充：扫描结果持久化缓存

用户反馈：刷新按钮没反馈；扫描到的模型关弹窗就消失。

- `AiAgentCliSettings.modelPool: HashMap<cli, Vec<CliModelCacheEntry>>` 持久化到 `app_settings`，按 CLI 隔离。

- 扫描池变化不静默收缩启用清单。
