## 1. 目标、范围与非目标

目标：滚动条低干扰；800×600 小窗口内所有业务页面可正常浏览与操作；缩放窗口时输入、选择和任务状态不丢失。

覆盖全部路由：看板 `/`、图库 `/library`、笔记列表 `/notes`、编辑 `/notes/:id`、发布 `/publish`、灵感 `/inspire`、搜索 `/search`、数据与经验库 `/data`、榜样 `/accounts`、账号 `/profile`、账号池 `/accounts/pool`、设置 `/settings`。包括各页详情、AI、筛选、批量操作、弹窗、空态、加载态、错误态和 Toast。

不包含：业务能力开发、数据库与后端契约、AI Provider、平台采集/发布、移动端、官网、品牌重做。不得通过提高窗口最小尺寸、整页缩放或普遍缩小字体来掩盖布局问题。保留默认 800×600 启动配置。业务不可用状态仍需准确呈现。

## 2. 已核对的问题

- index.css 全局滚动条为 6px，灰色滑块常驻；多滚动区域同时出现，视觉过重。
- Library.tsx 按偏好强制 2–8 列，详情并排占用 w-72；工具栏与浮动批量操作没有足够换行和宽度约束，截图出现逐字竖排、卡片极窄。
- App.tsx 的弹性主区需要检查 min-width/min-height 收缩链；侧栏、全局状态栏均占用有限空间。
- Notes.tsx 预览固定 230px；Inspire.tsx 抽屉有 420px 最小宽度；Settings.tsx 表单固定 160px 标签列。多页按 viewport 断点切列，未考虑侧栏和详情占用后的真实内容宽度。
- 截图是像素图，不能直接等同于 CSS 尺寸；以 WebView 实际 viewport 和元素宽高测量为准。

## 3. 统一设计规则

### 滚动条与滚动区域

1. 默认可见滑块约 4 CSS px，中性色低对比，轨道透明、圆角；滚动容器 hover、focus-within 或实际滚动时增强可见度。浅/深主题使用各自 token，不使用品牌色滑块。
2. 保留滚轮、触控板、键盘与拖动；不要全局 scrollbar-width:none。横向图片条可保留已有隐藏策略，但不能将必要表格滚动完全隐藏。
3. 优先 CSS；若必须监听滚动，使用共享实现、被动监听和清理，避免高频 React 更新。具体显隐效果受 WebKit 和系统滚动条设置影响，原生验收确认，不承诺完全覆盖系统偏好。
4. 页面只有一个主要纵向内容滚动区；独立抽屉/编辑器可各自滚动。给 flex 子级补齐必要 min-h-0/min-w-0，不用全局 overflow-x:hidden 掩盖被裁掉的控件。

### 可用宽度与状态保留

1. 页面内部优先基于容器实际宽度判断密度；外壳才使用窗口断点。容器查询可满足时优先 CSS；只有列数或面板模式确实需逻辑判断时才用共享 ResizeObserver。
2. 外壳建议 <960px 自动呈现 64px 图标侧栏；>=960px 恢复用户手动折叠/宽度偏好。自动模式不写入用户偏好；小窗口展开使用临时覆盖导航，选择后关闭。
3. 内部布局参考：内容宽 >=960px 可并排，640–959px 紧凑重排，<640px 单主区；最终门槛按各页主区最小可用宽度确定，记录实测值，不机械套用同一阈值。
4. 顶栏优先保留当前账号与数据状态；数量等次要信息折叠，长账号名截断且可查看完整值。标题和主要按钮不逐字折行；按钮使用不换行文字，操作组整体换行或收进“更多”。
5. 侧栏低高度时导航区独立可滚动，底部设置/账号池可达。页面间距可由 24px 收到 12–16px，正文维持现有阅读大小。
6. 详情/AI 窄屏改覆盖抽屉，有明确关闭入口；模态抽屉管理焦点、Escape 和遮罩，关闭恢复触发点焦点。宽窄模式切换不通过 key 重挂载编辑器或 AI 组件，不中断生成、不清除输入和选中。
7. 弹窗受 viewport 宽高限制：标题/关闭与底部动作可达，正文 min-h-0 内滚动；危险操作的确认语义不变。悬浮批量栏为其下方内容预留空间。

### R03 图库必须实现的细节

- 用户选择列数是偏好上限；建议卡片最小宽度约 140px、间距约 12px。实际列数 = min(偏好列数, 容器可容纳列数)，下限 1；具体值可按实测微调。
- 存储偏好值，不将临时自动减少后的列数回写。窗口放大或详情关闭后恢复偏好允许的列数。
- 滑块/列数提示不得显示“8列”却实际仅有3列而无解释，可写“3列（偏好8列）”或等价简洁反馈。
- 主区不足以承载卡片和工具栏时，详情覆盖展示；多选栏“已选 N 张”、合并生成、删除、取消不能逐字竖排；次要批量操作可进入更多。
- 详情和批量模式同时存在时操作清晰可达；遮罩不允许误点底层。保留已有缺失素材、回收站、不可用能力提示。

### R04 创作页面必须实现的细节

- 小窗口不强塞预览+正文+AI 三栏；提供“预览”和“AI 助手”入口，正文保存入口持续可达。
- 切换展示模式不得清除未保存标题/正文/标签、AI 历史、生成中状态或灵感生成结果。
- 低高度时上方提示可紧凑或折叠，正文仍有可编辑空间；素材条保持合理缩略图宽度，不被压成细条。
- 灵感抽屉取消硬性超过可用空间的最小宽度，底部重新生成/保存操作可达；保留正在生成、失败、空结果和已保存反馈。
