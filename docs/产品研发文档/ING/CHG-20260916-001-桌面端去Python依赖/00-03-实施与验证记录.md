- Tauri 设置页的“回收站”不再调用旧 HTTP 删除/恢复接口；本地运行时读取当前账号快照，恢复和永久清理均走 Rust command，并显示素材引用保护和文件清理警告。旧浏览器运行时保留原接口。
- 本地发布准备在状态写入失败时不会关闭确认弹窗，用户可以看到错误并重试；只有 `update_local_note_status` 成功后才记录“已确认发布”。平台提交仍由用户在外部发布页完成。
- 验证：`npm run build`、`cargo fmt --manifest-path client/src-tauri/Cargo.toml -- --check`、`cargo check --manifest-path client/src-tauri/Cargo.toml`、全量 `check:*` 脚本和 `git diff --check` 通过；未启动或操作用户原生窗口。
- 原生验收入口：`npm run tauri:qa`（使用 `.qa/desktop-workspace`）或用户自己的 `npm run tauri`；外部 Provider 认证、扩展消息、正式迁移和平台发布仍需用户验收或明确授权。
