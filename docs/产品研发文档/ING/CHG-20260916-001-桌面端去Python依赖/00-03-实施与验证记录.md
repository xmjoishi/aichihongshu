## 灵感页无限随机渲染修复

- 日期：2026-09-16。
- 现象：进入“灵感”页后，图库素材和榜样卡片持续随机切换，界面无法稳定。
- 根因：Tauri 本地快照在 render 中执行 `map`，每次都创建新的 `allItems`、`allNotes`、`allAccounts` 数组；三个随机池 effect 依赖这些数组并调用 `setState`，形成重渲染循环。
- 修复：在 `client/src/pages/Inspire.tsx` 用 `useMemo` 缓存三份本地转换数组，只在 Rust 快照的对应字段变化时更新；“刷新”按钮仍明确调用随机抽样。
- 验证：`npm run build`、`git diff --check` 通过；重新运行 `npm run tauri` 后 Vite 与 Rust Tauri 进程正常启动。
