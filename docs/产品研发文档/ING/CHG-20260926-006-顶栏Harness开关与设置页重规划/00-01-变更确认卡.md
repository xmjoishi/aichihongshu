# CHG-20260926-006 顶栏 Harness 开关与设置页重规划：变更确认卡

## 目标

1. 把 PC Harness（手机 Companion）开关提升到桌面顶栏右上角，一键开/关，并提供地址/令牌快捷面板。
2. 重划设置页信息架构，消除「通用」大杂烩与 AI 能力分裂。

## 现状

- 开关路径：设置 → 通用 →「手机 Companion（PC Harness）」（`client/src/pages/Settings.tsx` 的 `GeneralTab` / `PcHarnessSection`），层级过深。
- 设置页 Tab：通用 / AI 与 Agent / 提示词 / 回收站；其中「通用」含 7 个 Section：本地数据迁移与恢复、本地 AI CLI、外观主题、API 配置（旧服务）MiniMax、手机 Companion（PC Harness）、显示设置 HDR、账号人设（仅跳转）。
- 顶栏（`client/src/App.tsx` `app-topbar`）右侧仅有 `LocalRuntimeStatus`，有可用空位。
- PC Harness 运行时命令已具备：`pc_harness_status` / `start_pc_harness` / `stop_pc_harness` / `rotate_pc_harness_token`（`client/src/lib/local.ts`）。

## 范围

- 顶栏右上角新增 Harness 快捷控件：状态点 + 一键开/关 + popover（地址/令牌复制、轮换入口、「详细设置」跳转）。
- 设置页重划为五分区：通用 / AI 与 Agent / 提示词 / 手机 Companion / 数据与维护。
- 内容搬家：本地 AI CLI → AI 与 Agent；PC Harness → 独立「手机 Companion」Tab；本地数据迁移与恢复、回收站 → 数据与维护；API 配置（旧服务）折叠进数据与维护底部。
- 删除「账号人设」跳转卡片（「我的账号」页已有完整入口）。

## 非目标

- 不改动 PC Harness 协议、服务端监听、配对鉴权语义。
- 不改手机端配置页与客户端契约。
- 不迁移/清理旧 Python 路径或浏览器预览的 MiniMax 行为（仅 UI 收纳）。
- 不做设置项增删语义变更（不新增设置键、不删数据）。

## 已确认决定（2026-09-26 用户确认）

1. 顶栏形态：**开关 + 快捷面板**（状态点 + 一键开/关；点开可复制地址/令牌、跳详细设置）。
2. 设置页方向：**五分区**（通用 / AI 与 Agent / 提示词 / 手机 Companion / 数据与维护）。
3. 变更挂靠：**新建轻量 CHG**（本卡），独立验收。

## 待决事项

- 无（范围与形态已确认）。

## 验收条件

- AC-01：顶栏右上角可见 Harness 控件；未开启时显示「未开启」/关闭态，点击可开启监听；运行中显示开启态，点击可停止；状态与设置页一致。
- AC-02：点击顶栏控件弹出快捷面板，可复制手机连接地址与配对令牌，并能跳到设置「手机 Companion」详情。

- AC-04：「AI 与 Agent」含本地 AI CLI 检测；「数据与维护」含迁移恢复与回收站（及折叠的旧 API 配置）。
