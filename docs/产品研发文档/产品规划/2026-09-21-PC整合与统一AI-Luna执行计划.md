## 1. 最新决定与执行边界

用户指定顺序：PC 页签调整与整合 → AI 全面重构 → 手机接入 → 自动化深化。本顺序替代整体 Roadmap 原先优先交付手机切片的建议。

已确认：

- 看板改为概览；图库采用“素材库”作为执行名称，底层仍可使用资产概念。
- 灵感保留，整合自己的选题与榜样选题，榜样移入灵感；生成笔记后保留灵感和关联。
- 发布并入笔记；账号与数据合并。
- 搜索放 LOGO 下，为当前账号可访问模块提供全局搜索，不再作为独立业务页。
- 账号池保留独立管理入口和快速切换，交互参考 NOOMD 工作空间；不合并到当前账号资料页，也不解除账号数据隔离。
- AI 具有浮窗、侧栏、独立页面三种形态，共享会话与任务。设置支持 Model API、Agent CLI 两类接入。
- 手机首期同 Wi-Fi，使用 PC Harness；用户最终在小红书 App 发布，回填/核对；先以用户自己的租房家居账号验收。

本计划覆盖 PC 整合和统一 AI 的可执行任务；手机、自动采集、跨页自主 Agent、虚拟账户/共享资产仅明确接口和后续门槛，不在本批自动展开。

用户要求“给出计划，让 Luna 执行”，当前协作者只整理计划，不代发其他任务、不执行代码。Luna 接到用户执行指令后按本文开展，不重复确认已确定范围。

执行前遵循 AGENTS 与协作规则。为新增 PC/AI 范围建立独立 CHG（检查编号占用后分配），引用本文，补确认卡、技术设计、实施检查点；既有 CHG-20260916-001 继续管理去 Python 迁移，避免重复记录同一改动。旧浏览器路线与人工提交边界保留。

## 4. 第二批：统一 AI（B00–B07）

### 4.1 三种形态是一套会话

- 侧栏：与当前页面并排；可调整宽度，显示当前账号/对象和引用资料。
- 浮窗：默认指应用内可移动、可缩放面板；不得默认扩大成系统级常驻窗口或跨应用控制。先只读核对 NOOMD 实际布局交互后复用合适行为。
- 独立页面：主内容区完整助手工作区，适合长对话、历史会话和产物审阅；不是另开一套 AI 服务。
- 三种形态切换保持同一 conversationId/runId、输入草稿、附件、流式内容、所选模型、审批与产物；同一时刻一个活跃展示宿主，不重复订阅/发请求。
- 关闭视图不等于取消运行，停止按钮才取消；切换页签不丢任务。应用重启显示真实的中断状态，不伪造继续流式执行。
- 新建会话采用当前账号；已有运行固定账号和对象版本。跨账号切换隐藏原账号内容，保留其任务记录，返回后可恢复；不把旧流写到新账号。
- 路由变化可更新“当前页面”上下文，但发起任务时冻结作用域。显示已关联对象，允许解除/替换引用，不能静默修改正在编辑的其他笔记。

| 编号 | 工作 | 交付与验证重点 |
| --- | --- | --- |

| B01 | 接入设置与 Provider 适配 | Model API 与 Agent CLI 均可真实调用，默认选择持久化；凭据不入业务日志/明文普通库 |
| B02 | 统一会话/运行服务 | 在 PC 持久化历史、任务、事件与产物；已有 ai_runs/产物表和 localStorage 历史迁移兼容，不丢旧对话 |
| B03 | 全局 Copilot 宿主与三种形态 | 复用一个渲染主体和状态源；旧页内 AIPanel 按适配器迁入，去除重复浮动入口 |
| B04 | 页面 Context 与业务工具 | 素材查找/理解、选题创建、笔记修改提案、发布准备、数据解释；动作通过服务校验，不直接操纵页面 DOM |
| B05 | 最小定位与记忆 | 已确认事实/表达偏好/历史事件、来源与作用域；候选确认/编辑/删除；不同账号隔离 |
| B06 | 受控修改和未来 Agent 接口 | 修改差异、应用/撤回、版本冲突；工具声明范围与幂等；本批不启用自主跨页连续执行 |
| B07 | 能力实测与收口 | 三形态切换、两类接入、真实图片输入、取消/超时/重开、作用域回归；交用户原生验收 |

Model API 首批建议一个可配置兼容协议的实现（Base URL、模型、凭据引用），覆盖文本与一条真实多模态链路；其他协议按明确能力扩展，不承诺任意供应商即插即用。Agent CLI 沿用 claude/codex/opencode 候选与已有检测；安装存在、登录成功、文本、图片、工具、取消分别验证，未验证不宣称支持。某个 CLI 不可用不阻塞其他已验证接入。

Model API/Agent CLI 是接入类型；Copilot/Agent 是执行模式。API 也能驱动业务工具，CLI 也可以只提供回答。CLI 默认限制工具和工作目录，不能只靠提示词声称“禁止执行”；验证技术边界后才允许手机或后续 Agent 使用。

不要求本批实现动态模型市场、复杂自动路由或所有 CLI 图片能力。默认文本/图片选择可分开配置，缺少图片能力明确报错，不能仅传图片路径却声称模型看过图。

记忆起步用结构化信息和全文检索；自动从 AI 稿提炼的事实先待确认。门后旧塑料架/新金属架区分实体；油烟机例文新增的漏烟描述不能直接入事实。新建记忆服务与接口，不自动导入用户历史聊天，不替用户确认内容。

## 5. 服务拆分与未来接口

渐进抽取当前 db.rs/lib.rs，按实际变更落位 account/assets/inspiration/notes/publication/ai 服务；Tauri commands 负责参数与错误转换。不要先全仓搬文件再做产品。

业务命令显式携带 accountId、对象 ID、版本、requestId。账号池的 activeAccount 只表示当前 UI 上下文，不作为后台任务执行时隐式身份。预留 workspace/identity 概念但不实施共享资产迁移。

未来手机 LAN API 与桌面 command 调同一服务；任务生命周期不依赖 React 组件。首批仅形成契约，不开启网络监听、配对、手机数据库合并或手机代码改造。

发布复用现有 outbox/快照；AI 发布工具最多准备可审稿产物和交接，不执行最终平台提交。已有 Python CLI/MCP 与浏览器预览兼容路径不擅自删除；只有修改 Python 后端时按旧工程说明重启相应服务。
